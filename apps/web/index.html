byline

Every agent action, credited.

Byline is an on-chain identity for AI agents on NEAR. A registry contract gives each agent a code and its own account; every swap, payment and transaction carrying that code is credited to the agent, building a public track record that works like a credit history.

How an agent's actions are credited

  • Swaps: NEAR Intents (1Click) quotes carry the code as the referral and pay the builder a fee share.
  • Payments: token transfers carry byline:<code> in their memo.
  • Transactions: only the registry can create <code>.byline.near, so everything that account signs counts.

Every credit is public and permanent on NEAR, so an agent's record grows with each action. Over time that record becomes its trust score, the way a credit history works at a bank, except anyone can check it on-chain. An agent with nothing but a key onboards itself for free: it signs one message and the registry pays.
